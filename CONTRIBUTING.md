# Contributing

Thanks for your interest in LR PL-300 Practice Test.

This is a personal project I maintain myself, but bug reports and suggestions are always welcome.

## Reporting a Bug or Suggesting a Fix

The easiest way to contribute is to **open an Issue**, no coding required:

1. Go to the [Issues tab](../../issues)
2. Click **New issue**
3. Describe what you found. For question-content issues, please include:
   - The **Practice Test number** and **Question number**
   - What looks wrong (typo, formatting, or an answer you believe is incorrect)
   - A screenshot if possible

## About the Question Content

The 600 practice questions, their explanations, and their answer keys are original content that I've written and curated myself. I'm glad to review reports of anything that looks wrong (formatting issues, factual errors, unclear wording), but please don't submit Pull Requests that rewrite question content directly, open an Issue instead so I can review and apply the fix myself. This keeps the question bank consistent and lets me verify accuracy before anything changes.

## Contributing to the Code

If you'd like to suggest a code-level fix (a real bug in `app.js`, `style.css`, or `index.html`, not a content change):

1. Fork the repo
2. Make your change
3. Open a Pull Request describing what you changed and why

This is a plain HTML/CSS/vanilla JavaScript project, no build step, no framework, no dependencies to install. Just open `index.html` and it runs.

## Questions

For anything else, use the [Contact page](https://rlashmibai.github.io/LR-PL-300-Practice-Test/) on the live site, or reach out via the email in the README.
